# Lu Jia / 贾路 — Academic Homepage

Static website files from the approved v5 homepage. No résumé file is included.

## Publish

1. Sign in as `LuJia-USTB` and create the public repository `lujia-ustb.github.io`.
2. Upload the contents of this archive to the repository root. `index.html` must be at the root; do not upload the ZIP itself or place the contents in an extra outer folder.
3. In **Settings → Pages**, select **Deploy from a branch**, then `main` and `/(root)`, and save.

The intended website address is https://lujia-ustb.github.io/ after successful deployment. Creating this package does not publish the website.
